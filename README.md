# GeoSpectre-IP-Geolocation_Lookup_Tool

GeoSpectre is a CLI-based IP Geolocation Lookup Tool which provides you with an interactive command-line UI that allows you to enter any IP Address and view its precise geographical location (geolocation).

# Future Optimisation & Expansion

In future updates, I will aim to be introducing new modules to GeoSpectre to make the user experience better for all of you.
